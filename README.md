# my-gmeet-bot


## Prerequisites

Before configuring or running the application, complete the [Google Cloud and Google Meet API setup](docs/google-cloud-setup.md).

That guide covers creating Google Cloud OAuth credentials, enabling the Google Meet REST API, adding test users, and keeping downloaded OAuth credentials out of Git.

## Project roadmap

See the [future plan](docs/future-plan.md) for the planned flow from submitting a Google Meet link through joining, storing discussion data, and querying it through a chatbot UI.
